# Plemu artwork

The PNG files are the supplied Plemu pixel face and wordmark masters. Their pixels
and embedded creator credits are preserved. Use the pixel face and wordmarks for
primary branding. The older SVG remains available for secondary decorative uses.

These files are not an open-source grant for the brand. See the [repository copyright notice](../../COPYRIGHT.md) for the distinction between Plemu-owned and third-party material.
